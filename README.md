# Герои Капитала

Пошаговая стратегия в духе «Героев Меча и Магии III», которая учит финансовой грамотности. Армия — это портфель: каждое существо — пакет ценных бумаг, и его цена меняется вместе с рынком.

Игра работает прямо в браузере: на телефоне, планшете и компьютере. Ничего устанавливать не нужно.

## Что внутри

- Карта приключений с зонами, проходами под охраной и сокровищами в «карманах». Есть шесть шаблонов генератора («Дуэль», «Крест», «Кольцо», «Лабиринт», «Архипелаг», «Сердце рынка») и две авторские карты («Две реки», «Золотая лихорадка»).
- Шесть фракций со своими существами, городами-панорамами и героями.
- Бои на гексах, заклинания трёх школ, артефакты в слотах, боевые машины.
- Компьютерные соперники, бои героев между собой, осада и грабёж замков.
- Кампания из трёх глав с сюжетом об инвестициях.

## Как опубликовать на GitHub Pages с iPhone

1. Сохраните архив `geroi-kapitala-github.zip` в приложение «Файлы» и нажмите на него — появится папка `geroi-kapitala`.
2. На github.com создайте репозиторий: **New repository**, задайте имя, например `geroi-kapitala`, отметьте **Public** и нажмите **Create repository**.
3. В репозитории нажмите **Add file → Upload files → choose your files**. Откройте папку `geroi-kapitala` и выделите файлы: **Выбрать → Выбрать все**.
   GitHub принимает не больше 100 файлов за раз. Если выбор не проходит, загрузите в два приёма: сначала всё, кроме файлов `snd_*.mp3`, затем сами `snd_*.mp3`.
4. Внизу страницы нажмите **Commit changes**.
5. Откройте **Settings → Pages**. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку **main** и папку **/ (root)**, затем нажмите **Save**.
6. Через 1–2 минуты игра откроется по адресу `https://ВАШ_ЛОГИН.github.io/geroi-kapitala/`.

Чтобы игра запускалась как приложение во весь экран, откройте адрес в Safari и выберите **Поделиться → На экран «Домой»**.

## Файлы

Все файлы лежат в одной папке без подпапок, чтобы их можно было загрузить с телефона.

- `index.html` — вся игра (код, стили, разметка).
- `units.png`, `units2.png` — атласы существ и героев.
- `terrain.png` — атлас местности, препятствий и предметов.
- `tex_*.jpg` — рисованные текстуры земли.
- `pan_*` — панорамы городов.
- `map_*.jpg` — исходные иллюстрации кампании (по ним строится география).
- `icons.jpg` — иконки интерфейса.
- `music_*.mp3`, `snd_*.mp3` — музыка и звуки.
- `manifest.webmanifest`, `icon-*.png` — запуск как приложение.
